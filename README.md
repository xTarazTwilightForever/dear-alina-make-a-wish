# Dear Alina, make a wish ♡

Маленькое приключение ко дню рождения моей Алины — котик и кошечка ищут путь друг к другу. ♡

## Локальная разработка

Нужен Node.js 22.12+ или 24+ и npm.

```sh
npm install
npm run dev
```

Открой http://127.0.0.1:5173. Приватность репозитория не влияет на локальный запуск. Изменения компонентов и стилей появляются в браузере при сохранении файлов.

## Проверка и сборка

```sh
npm run format:check
npm run typecheck
npm test
npm run build
npm run preview
```

Готовые файлы появляются в `dist/`. Адрес предпросмотра сборки — http://127.0.0.1:4173.

## Структура

```text
src/
  app/                  # Каркас приложения и общие стили
  assets/illustrations/ # Исходные иллюстрации
  content/              # Письмо, пожелания и подписи альбома
  features/
    welcome/            # Первая открытка
    heart-game/         # Игра, модель движения и стили
    album/              # Галерея и просмотр иллюстраций
    letter/             # Письмо и загадывание желания
    music/              # Управление мелодией
  shared/characters/    # Общие векторные персонажи
  main.tsx              # Точка входа
tests/                  # Проверки логики игры
```

Каждая глава содержит собственные компоненты и стили. Общие персонажи используются и в открытке, и в игре. Логика движения отделена от React: кошечка приближается к неподвижному белому котику, каждое сердечко можно собрать один раз.

Письмо редактируется в `src/content/birthday.ts`, подписи и порядок иллюстраций — в `src/content/album.ts`. Все семь присланных изображений сохранены в проекте. Альбом поддерживает просмотр целиком, стрелки клавиатуры и закрытие по Escape.

## Технологии

React, TypeScript в строгом режиме и Vite. Отдельный сервер и база данных пока не нужны. Котики нарисованы в SVG, музыка синтезируется браузером после нажатия. Шрифты загружаются из Google Fonts с запасными системными шрифтами.

Тесты проверяют сбор сердечек в произвольном порядке, защиту от повторного сбора и движение только кошечки.

## Размещение

Автоматическая публикация не настроена. Проект запускается локально. Относительные пути сборки позволяют позже разместить его в подпапке GitHub Pages. Перед подарком нужно заменить черновик письма своим текстом и отдельно настроить доступ к сайту.
