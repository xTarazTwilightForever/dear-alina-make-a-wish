# Dear Alina, make a wish ♡

Личное признание Иксика в любви к Алине ко дню её 18-летия, 8 ноября 2026 года. В шапке открытки написано Моя дорогая Алина.

## История и порядок глав

Открытка → пролог Тишки → Тропа сердечек → Мост нежности → Признание Иксика → личное письмо → альбом мечтаний.

- На Тропе сердечек нужно открыть пять посланий Иксика.
- На Мосту нежности нужно найти шесть пар карточек.
- В Признании Иксика нужно собрать фразу Моя Алина, я люблю тебя. Ты мой дом.. Правильно выбранное последнее слово сразу открывает письмо.
- Картинки доступны по кнопке после письма. Из альбома можно вернуться к письму.

Тишка скучает у сестры Алины Кристины и просит маму скорее приехать из деревни в Павлодар. Это упоминается только на первой странице пролога. На всех трёх фотографиях он на руках у Алины. Иногда Тишка оговаривается, называя Иксика Никитой.

Все поздравления и признания исходят от Иксика. Он обращается к Алине Хозяйка, Пантерка и Моя Алина. Иллюстрации показывают мечты о будущей первой встрече. Финальное письмо содержит авторский текст Никиты с полной подписью.

## Локальная разработка

Нужен Node.js 22.12+ или 24+ и npm.

```sh
npm install
npm run dev
```

Открой http://127.0.0.1:5173. Приватность репозитория не влияет на локальный запуск.

Музыка включается с первого нажатия на открытку и сопровождает все главы. Кнопок и индикаторов музыки нет. До первого жеста браузер может блокировать звук. При уходе с вкладки мелодия приостанавливается, при возвращении возобновляется. Если требуется новый жест, следующее касание повторяет запуск.

## Проверки для разработчика

Проверки выполняет владелец проекта вручную:

```sh
npm run format:check
npm run typecheck
npm test
npm run build
npm run preview
```

Существующие тесты проверяют модель Тропы сердечек. Остальное следует пройти вручную: карточки, порядок слов, подсказку, прямой переход к письму, альбом после письма и возобновление музыки.

Готовые файлы сборки появляются в `dist/`. Предпросмотр сборки доступен по адресу http://127.0.0.1:4173.

## Структура

```text
src/
  app/                   # Порядок глав, переходы и общие стили
  assets/
    illustrations/       # Двадцать иллюстраций Алины и Иксика
    photos/              # Три фотографии Тишки на руках у Алины
  content/               # История, письмо, подписи и игровые слова
  features/
    access/              # Вход с паролем Иксик
    welcome/             # Обложка открытки
    story/               # Пролог от лица Тишки
    adventure/           # Карта трёх локаций
    heart-game/          # Тропа сердечек
    memory-game/         # Мост нежности
    message-game/        # Признание Иксика
    letter/              # Письмо и переход к альбому
    wish/                # Звёздное небо для желания
    album/               # Альбом с просмотром целиком
    music/               # Музыка без видимых элементов управления
    effects/             # Фоновые огоньки и сердечки при нажатиях
  shared/
    characters/          # Общие векторные персонажи
    dialogue/            # Реплики котика на фотографиях
    lib/                 # Перемешивание игровых элементов
  main.tsx               # Точка входа
tests/                   # Существующие проверки Тропы сердечек
```

Тексты истории находятся в `src/content/story.ts`, письмо в `src/content/birthday.ts`, подписи альбома в `src/content/album.ts`. Порядок глав перечислен в `src/app/chapters.ts`. Переходы задаются в `src/app/App.tsx`.

Прогресс живёт в памяти страницы. Обновление страницы начинает историю заново. Кнопка с названием в шапке возвращает к обложке.

## Технологии и размещение

React, TypeScript в строгом режиме и Vite. Сервер и база данных не требуются. Котики нарисованы в SVG, музыка синтезируется браузером. Шрифты загружаются из Google Fonts с запасными системными шрифтами.

Автоматическая публикация не настроена. Проект запускается локально. Относительные пути сборки подходят для подпапки GitHub Pages. Доступ к опубликованному сайту настраивается отдельно.

## Вход, анимации и фотографии

Перед открыткой появляется экран с паролем `Иксик`. Также принимается `brcbr`, то же имя в английской раскладке. Введённый текст виден. Регистр и пробелы по краям не учитываются. Это игровой вход в открытку, а не серверная авторизация: исходники и статические файлы по-прежнему доступны посетителю, получившему к ним доступ. После обновления страницы пароль требуется снова.

У пяти сердечек на Тропе сердечек собственные цвета. Текст открытого признания окрашивается в цвет выбранного сердечка. На Мосту нежности карточки переворачиваются в пространстве и слегка наклоняются при наведении мыши.

Кнопка загадывания желания открывает отдельное звёздное небо со свечкой и падающей звездой. Надпись подтверждает, что желание обязательно сбудется. Окно закрывается кнопкой или Escape. Системная настройка уменьшения движения отключает анимации.

Все двадцать две иллюстрации и три фотографии Тишки сопровождаются небольшими диалоговыми окошками от Никиты, белого котика Иксика. В полноразмерном просмотре альбома реплика тоже доступна. Солнечный день, Ещё пять минуточек и Маленькое укрытие заменены новыми изображениями.

Плитки альбома размещаются в обычной сетке по три в строке, строго слева направо по номерам, затем на следующей строке. Новые страницы идут первыми, главное признание Иксика остаётся последним. Превью имеют одинаковую квадратную область, изображение целиком вписывается в неё, а карточки одной строки выровнены по высоте. На телефоне остаётся одна колонка. При наведении меняются только обводка и тень, карточки и изображения не двигаются и не масштабируются. Многоколоночное перетекание удалено.

## Новые страницы альбома

В начале альбома находятся 15 новых иллюстраций с отметкой Новая страничка. Первыми идут две истории, рассказанные Алиной: она поставила картошку вариться и затем заметила, что плита разбита; её сестра случайно разбила собственный телефон. После новых страниц размещены прежние семь. У каждой страницы своё название, описание сцены, размеры исходного файла и отдельная реплика Никиты. Названия файлов приведены к именам Алины, Иксика и Тишки вместо общих обозначений персонажей.

Альбом назван Дневник Иксика и помечен 2026 годом. После текущих иллюстраций подготовлены места для 2027, 2028, 2029 и следующих лет с посланиями о будущих воспоминаниях. Это открытые страницы ожидания, без кнопок или вымышленных фотографий будущих событий. Содержимое будущих лет задаётся в `futureDiaryPages` в `src/content/album.ts`.

Среди новых сюжетов: Иксик создаёт сайт для Алины, совместная игра, объятия у зеркала, любимые пони, выбор нарядов, выпечка, локоны и два котика, нарисованный подарок, беговая дорожка, забота об Алине, забота о Тишке, лес маленьких Иксиков и ожидание сообщения Алины.

Дополнительные эффекты: мягкие фоновые огоньки по краям страницы, небольшие сердечки при нажатиях на кнопки, световой блик внутри иллюстрации при наведении и плавное появление фотографии при перелистывании. Эффекты учитывают системную настройку уменьшения движения и не перехватывают нажатия. Пароль Иксик остаётся независимым от регистра, включая смешанные большие и маленькие буквы.

## Свечка и оформление для телефона

Вся история оформлена в оттенках звёздного неба с розовым свечением. Главы открываются с мягким эффектом перелистывания. На компьютере курсор выглядит как сердце, а при наведении на кнопки появляются маленькие сердечки. На сенсорном экране эффекты запускаются касанием.

Для узких экранов, включая iPhone 15, альбом перестроен в одну колонку. Реплики Никиты увеличены, выделены контрастными окошками и не зависят от наведения. На каждой картинке есть подсказка о послании ниже. В полноразмерном просмотре изображение занимает меньше высоты, чтобы подпись и реплика оставались заметнее. На Мосту нежности послание находится над карточками и закрепляется при прокрутке.

После личного письма можно загадать желание и задуть свечку. Нажатие на свечу или кнопку работает без микрофона. Отдельная кнопка позволяет запросить микрофон и задуть свечу дыханием. Поток анализируется локально, звук не записывается и не отправляется. Микрофон отключается после задувания, закрытия окна или ухода с вкладки. Для доступа к нему нужен безопасный контекст, например HTTPS или localhost. При отказе в разрешении остаётся обычная кнопка.

Желание засчитывается только после задувания свечи. Повторное загадывание блокируется до открытия альбома. После перехода в альбом блокировка сбрасывается. Новое прохождение и обновление страницы также сбрасывают состояние. Хранилище браузера для желания не используется. Перед свечкой есть пояснение, пламя мерцает до задувания.

Портрет Иксика находится последним и выделен как главное признание Никиты. Уточнены истории о Dyson, фотографии книги и разлитом энергетике, лекарствах для Алины, спасении Тишки, лесной сказке с 400 котятами и ожидании возвращения Алины из деревни.

Эти изменения не проверялись запуском тестов, сборки или браузера по просьбе владельца. Мобильный вид, звук, доступ к микрофону и задувание нужно проверить на её устройстве.

## Личное письмо и сопровождение Тишки

Письмо оформлено как тёмная личная страница с датой, обращением, абзацами и отдельным блоком подписи. Исходная подпись Никиты сохранена без изменений и отображается белыми чернилами средствами CSS. Имя и сердечко находятся в отдельных областях, а текст после появления страницы не сохраняет трёхмерных преобразований.

Между главами появляется короткое перелистывание с Тишкой. В минииграх он сопровождает Алину небольшими подсказками. На время перехода навигация блокируется, затем фокус возвращается к заголовку новой главы. Настройка уменьшения движения учитывается. Лапки на карточках и лапки Тишки белые, прямоугольная обводка свечи заменена мягким свечением при фокусе с клавиатуры. Истории о лекарствах и нарядах уточняют, что подарки были инициативой Никиты.

После альбома кнопка Конец открывает финальное признание Никиты о любви к Алине и мечте о совместной жизни и семье. Эта кнопка также доступна при просмотре последней иллюстрации. Абзацы письма начинаются без отступа и расположены компактнее.

Счётчик в письме показывает полные дни, часы, минуты и секунды с 1 ноября 2026 года, 11:10 по времени Павлодара (UTC+05:00). ## Голосовое поздравление

Перед голосовым подключено гитарное видео Никиты: `src/assets/video/birthday-guitar.mp4`, около 16 секунд. Запись подготовлена в H.264/AAC, 1280×720, с метаданными в начале MP4 для потокового запуска. В блоке есть обложка из самого ролика (`birthday-guitar-poster.jpg`), кнопка воспроизведения по центру и посвящение Alluka. После запуска доступны обычные элементы управления видео, а при ошибке отображается ссылка на сам файл. Воспроизведение на iPhone остаётся встроенным в страницу.

После задувания свечки используется отдельная звуковая дорожка этой записи: `src/assets/audio/birthday-guitar.m4a`, около 0,5 МБ. Поэтому ради мелодии не загружается всё видео. Если дорожка отсутствует, сохраняется возможность проиграть звук самого ролика. Запуск вызывается сразу при задувании. Если автоматическое воспроизведение отклонено браузером, появляется приглашение нажать кнопку. Мелодию можно приостановить или включить повторно; закрытие свечки и переход в альбом останавливают её. В финале видео запускается вручную и сохраняет пропорции. Музыка становится тише на время видео, гитарной мелодии или голосового. При включении новой личной записи предыдущая приостанавливается. При замене ролика нужно обновить также его обложку и аудиодорожку.

В финале подготовлено место для голосового Никиты. Пока записи нет, отображается спокойная заглушка без неработающей кнопки воспроизведения. Для подключения положи одну запись в `src/assets/audio/` с именем `nikita-message.m4a` или `nikita-message.mp3` (также поддерживаются ogg и wav). Удали прежний вариант, если меняешь формат. После следующей сборки и публикации вместо заглушки автоматически появится плеер. Запись запускается самой Алиной. На время прослушивания фоновая музыка становится тише и возвращается к прежней громкости после паузы, окончания записи или ухода из финала.

Пожелания в существующих сердечках, парах карточек и абзацах письма обновлены: больше внимания мечтам Алины, её занятиям, свободе выбора, здоровью, отдыху и радостям наступающего года. Количество посланий и абзацев письма сохранено.

## Котики и повторное прохождение

Нарисованных котиков на экране пароля, приветствии, Тропе сердечек и в подсказках можно погладить нажатием. Каждый отвечает пятью репликами по очереди. Первая реплика Иксика начинается со слов Моя Алина и рассказывает, как Никита перечитывал письмо. Тишка зовёт маму проходить приключение и остаётся её проводником. Над котиком появляется небольшое облачко без затемнения и блокировки страницы. Повторное нажатие на котика или А ещё показывает следующую реплику. Положение облачка учитывает края экрана, прокрутку и экранную клавиатуру. Его можно закрыть крестиком, нажатием снаружи или Escape; при выборе другого котика прежняя реплика скрывается.

История проходится последовательно. Свободная навигация к открытым главам и сохранение закладок удалены. Из альбома можно перейти к финалу, а в финале доступна кнопка Пройти приключение ещё раз: она возвращает к истории Тишки и запускает миниигры заново. После голосового есть приглашение написать Никите о впечатлениях. Сердечко и содержимое блока голосового, а также кнопка повторного прохождения выровнены по центру.

## Созвездие Alluka

Перед голосовым в финале находится созвездие Alluka в форме буквы А. Шесть звёзд открывают послания Никиты о доброте, нежности, любопытстве, заботе, улыбке Алины и о ней самой. При появлении созвездия в поле зрения линии постепенно прорисовываются, звёзды мерцают, а после касания появляется световое колечко. Открытые звёзды и линии между ними загораются теплее. Рядом с датой 8 ноября добавлен знак Скорпиона. Рисунок остаётся личной буквой Алины, а не картой астрономического созвездия. Это необязательная часть истории, а не дополнительное испытание. Кнопки доступны с клавиатуры и достаточно крупные для касания, реплика при необходимости прокручивается в поле зрения. Настройка уменьшения движения отключает анимацию. Ник Alluka также добавлен на приветственную страницу.
