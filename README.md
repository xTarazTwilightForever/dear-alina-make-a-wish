# Dear Alina, make a wish ♡

Маленькое приключение ко дню рождения любимой хозяйки Алины. Её серый котик Тишка ведёт маму хозяйку по звёздной тропе к белому котику Иксику.

## История

Открытка → пролог Тишки с тремя фотографиями → тропа сердечек → мост нежности → признание Иксика → встреча → альбом → личное письмо.

Три мини-игры без таймера и проигрышей:

- Зажечь пять сердечек и открыть дорогу.
- Найти шесть пар карточек с символами любви.
- Собрать признание «Моя хозяйка, с тобой я дома.» из перемешанных слов. Тишка может подсказать порядок.

Тишка — серый котик с белой грудкой. Иксик — белый котик с фиолетовой чёлкой и розовой прядью. Алина — их любимая хозяйка; Тишка обращается к ней «Мама хозяйка».

## Локальная разработка

Нужен Node.js 22.12+ или 24+ и npm.

```sh
npm install
npm run dev
```

Открой http://127.0.0.1:5173. Приватность репозитория не влияет на локальный запуск.

Музыка запускается с первого нажатия на открытку и сопровождает все главы. Выбора «без музыки» нет. До первого жеста браузер может блокировать звук. При уходе с вкладки мелодия приостанавливается, при возвращении возобновляется; если браузер требует новый жест, следующее касание повторяет запуск.

## Проверки для разработчика

Проверки выполняются владельцем проекта вручную:

```sh
npm run format:check
npm run typecheck
npm test
npm run build
npm run preview
```

`npm test` содержит существующие проверки модели тропы сердечек. Новые игры нужно пройти вручную: проверить несовпавшие и найденные пары, исправление порядка слов, подсказку, повторное прохождение и музыку после возврата на вкладку.

Готовые файлы сборки появляются в `dist/`. Адрес предпросмотра сборки — http://127.0.0.1:4173.

## Структура

```text
src/
  app/                   # Переходы между главами, общие стили
  assets/
    illustrations/       # Семь иллюстраций альбома
    photos/              # Три фотографии Тишки
  content/               # История, письмо, подписи и игровые слова
  features/
    welcome/             # Обложка открытки
    story/               # Пролог от лица Тишки
    adventure/           # Общая карта трёх испытаний
    heart-game/          # Тропа сердечек
    memory-game/         # Карточки моста нежности
    message-game/        # Признание из перемешанных слов
    reunion/             # Встреча хозяйки и котиков
    album/               # Альбом с просмотром целиком
    letter/              # Письмо и загадывание желания
    music/               # Непрерывная мелодия приключения
  shared/
    characters/          # Общие векторные персонажи
    lib/                 # Перемешивание игровых элементов
  main.tsx               # Точка входа
tests/                   # Существующие проверки тропы сердечек
```

История и игровые фразы редактируются в `src/content/story.ts`, письмо — в `src/content/birthday.ts`, альбом — в `src/content/album.ts`. Главы перечислены в `src/app/chapters.ts`, переходы между ними задаются в `src/app/App.tsx`.

Состояние приключения живёт в памяти страницы. Обновление страницы начинает историю заново. Кнопка в шапке возвращает к обложке; повторный вход в игру начинает её заново.

## Технологии и размещение

React, TypeScript в строгом режиме и Vite. Отдельный сервер и база данных пока не нужны. Котики нарисованы в SVG, музыка синтезируется браузером. Шрифты загружаются из Google Fonts с запасными системными шрифтами.

Автоматическая публикация не настроена. Проект запускается локально. Относительные пути сборки позволяют позже разместить его в подпапке GitHub Pages. Перед подарком нужно заменить черновик письма своим текстом и отдельно настроить доступ к сайту.
