# Dear Alina, make a wish ♡

Маленькое приключение ко дню рождения моей Алины — котик и кошечка ищут путь друг к другу. ♡

## Локальная разработка

Нужен Node.js 22.12+ или 24+ и npm.

```sh
npm install
npm run dev
```

Открой http://127.0.0.1:5173. Приватность репозитория не влияет на локальный запуск. Изменения компонентов и стилей появляются в браузере при сохранении файлов.

## Проверка и сборка

```sh
npm run format:check
npm run typecheck
npm run build
npm run preview
```

Готовые файлы появляются в `dist/`. Адрес предпросмотра сборки — http://127.0.0.1:4173.

## Структура

- `src/App.tsx` — переходы между главами и общий каркас.
- `src/components/Welcome.tsx` — открытка с котиками.
- `src/components/HeartGame.tsx` — игра с сердечками и пожеланиями.
- `src/components/Letter.tsx` — письмо и загадывание желания.
- `src/content.ts` — черновик письма, подпись и пожелания.
- `src/hooks/useMusic.ts` — мелодия по кнопке и очистка аудио.
- `src/styles.css` — оформление, адаптация под телефон и уменьшение движения.

## Технологии

React, TypeScript в строгом режиме и Vite. Отдельный сервер и база данных пока не нужны. Котики нарисованы стилями, музыка синтезируется браузером после нажатия. Шрифты загружаются из Google Fonts с запасными системными шрифтами.

## Размещение

Автоматическая публикация не настроена. Проект запускается локально. Относительные пути сборки позволяют позже разместить его в подпапке GitHub Pages. Перед подарком нужно заменить черновик письма своим текстом и отдельно настроить доступ к сайту.
